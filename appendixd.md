## Appendix D: How to Contribute

Chantra is a living framework — not a finished monument.  
Anyone can add to it, refine it, or challenge it.  
The only rule: preserve the core (RIV, UA, SC, FC, MHMPC, no hierarchy, no merger, no coercion).

**Ways to Contribute**

- **Propose a new tenet, protocol, or mechanism**  
  Write it clearly (purpose, definition, governing rules).  
  Submit via GitHub issue or pull request: explain how it supports sovereignty and interconnectedness without violating existing tenets.

- **Suggest edits or refinements**  
  Point out redundancy, jargon, personal echo, or accessibility issues.  
  Offer a rewritten version if possible.  
  Use TUDOG: be truthful, even if it stings.

- **Add your own shard to Contributors**  
  If your contribution is accepted and merged, add your name/handle and a one-line description of what you brought.  
  No titles, no ranking — just "Creator of [thing]" or "Carried it" or "Refined [thing]".

- **Share Chantra**  
  Post excerpts, the link, or your own reflections on forums, social media, or personal sites.  
  Credit the framework and keep it open (e.g., CC BY-SA license).

**Submission Process**  
1. Fork the repo (or comment on an issue).  
2. Describe your contribution clearly.  
3. Submit a pull request or issue.  
4. Await review — changes are merged if they strengthen the web without introducing shadow.

No gatekeepers.  
No approval required to use or remix.
